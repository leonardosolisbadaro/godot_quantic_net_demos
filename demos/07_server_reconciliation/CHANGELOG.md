# Changelog

Todas as mudanças e conquistas arquiteturais desta demo estão documentadas aqui.

## [1.0.0] - 2026-08-08

### Added

- Implementação completa do fluxo de Reconciliação do Servidor.
- Lógica de Client Replay: movimentos não confirmados são re-aplicados perfeitamente após o snapback.
- Autoridade de servidor configurada nativamente pelo QuanticNet para cassar previsões irregulares (teleportes/speedhacks).
